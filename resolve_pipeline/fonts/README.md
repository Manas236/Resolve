# Caption fonts

Anton and Bebas Neue come from the Google Fonts OFL distribution. Resolve Montserrat Black is a renamed static instance of the Google Fonts Montserrat variable font at weight 900. Each upstream OFL notice is included alongside the font.

Poppins SemiBold is the face for P, L, F1 and F4. The unmodified font and accompanying OFL are from google/fonts, ofl/poppins.
