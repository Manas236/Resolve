# Caption presets

Play the three matched previews in **Settings → Caption previews**. Select Anton, Bebas Neue, or Montserrat Black and save to set the preset for future renders. The preview uses the same test pattern, bass pulse, text, and timing across all three variants so you can compare treatment. Generate the files locally with `python -m resolve_pipeline.caption_preview` or the dashboard's **Generate preset previews** button. The resulting MP4s are local review artifacts.
